# HS 2022 catalog source

`hs2022.json` is the complete HS 2022 reference catalog published by the United Nations Statistics Division and served by the official UN Comtrade API.

- Source: `https://comtradeapi.un.org/files/v1/app/reference/H6.json`
- Classification: `H6` / `HS2022`
- Imported nodes: 6,940 including the catalog root; application rows exclude only `TOTAL`
- Retrieved: 2026-09-12

The original source fields are preserved. UI names remove only the redundant `<code> - ` prefix.
